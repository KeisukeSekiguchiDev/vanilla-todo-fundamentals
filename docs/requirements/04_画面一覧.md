### ELM-002: タスク入力欄

| 項目 | 内容 |
|-----|------|
| 要素ID | ELM-002 |
| 要素名 | タスク入力欄 |
| HTML要素 | input type="text" |
| ID属性 | todo-input |
| プレースホルダー | 「タスクを入力してください」 |
| 最大文字数 | 200文字（超過分は切り捨て） |

#### 動作仕様

| 操作 | システムの動作 |
|------|---------------|
| 文字入力 | 入力内容がリアルタイムで反映される |
| Enterキー押下 | タスクが追加される（FR-001-04） |
| タスク追加後 | 入力欄が空になる（FR-001-08） |

### ELM-004: フィルタボタン群

| 項目 | 内容 |
|-----|------|
| 要素ID | ELM-004 |
| 要素名 | フィルタボタン群 |
| HTML要素 | div > button x 3 |
| クラス | filter-buttons |

#### ボタン構成

| ボタン | ラベル | data属性 | 初期状態 |
|--------|--------|---------|---------|
| フィルタ: すべて | 「すべて」 | data-filter="all" | 選択状態（アクティブ） |
| フィルタ: 未完了 | 「未完了」 | data-filter="active" | 非選択状態 |
| フィルタ: 完了 | 「完了」 | data-filter="completed" | 非選択状態 |

#### 動作仕様

| 操作 | システムの動作 |
|------|---------------|
| ボタンクリック | 該当フィルタがアクティブになる |
| フィルタ切替 | 条件に合致するタスクのみ表示される |

#### 表示スタイル

| 状態 | スタイル |
|------|---------|
| アクティブ | 背景色: 強調色、文字色: 白 |
| 非アクティブ | 背景色: グレー系、文字色: 黒 |

## 5. 画面遷移

本アプリケーションは単一画面（SPA）構成のため、画面遷移は発生しない。全ての操作はメイン画面（SCR-001）内で完結する。

```
[メイン画面 SCR-001]
       |
       +---> タスク追加（画面内更新）
       +---> タスク削除（画面内更新）
       +---> 完了切替（画面内更新）
       +---> フィルタ切替（画面内更新）
       +---> ページ再読込 ---> [メイン画面 SCR-001]（データ復元）
```

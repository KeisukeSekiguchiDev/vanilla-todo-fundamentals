## 3. 互換性要件

### NFR-001: ブラウザ対応

| 項目 | 内容 |
|-----|------|
| 要件ID | NFR-001 |
| 項目名 | ブラウザ対応 |
| 優先度 | SHALL（必須） |

#### 要件内容

| 仕様ID | 仕様内容 |
|--------|---------|
| NFR-001-01 | システムはGoogle Chrome最新版で正常に動作する |
| NFR-001-02 | システムはMozilla Firefox最新版で正常に動作する |
| NFR-001-03 | システムはMicrosoft Edge最新版で正常に動作する |
| NFR-001-04 | システムはSafari最新版で正常に動作する |
| NFR-001-05 | Internet Explorerは対象外とする |

#### 検証方法

- 各ブラウザの最新版で全機能の動作確認を実施する
- 確認項目: タスク追加、削除、完了切替、フィルタリング、データ永続化

---

### NFR-002: レスポンシブ対応

| 項目 | 内容 |
|-----|------|
| 要件ID | NFR-002 |
| 項目名 | レスポンシブ対応 |
| 優先度 | SHALL（必須） |

#### 要件内容

| 仕様ID | 仕様内容 |
|--------|---------|
| NFR-002-01 | システムはPC画面（幅1024px以上）で適切にレイアウトされる |
| NFR-002-02 | システムはタブレット画面（幅768px〜1023px）で適切にレイアウトされる |
| NFR-002-03 | システムはスマートフォン画面（幅767px以下）で適切にレイアウトされる |
| NFR-002-04 | 最小対応幅は320pxとする |
| NFR-002-05 | タッチ操作でボタン、チェックボックスが操作可能なサイズを確保する（最小タップ領域44x44px） |

#### ブレークポイント定義

| デバイス | 画面幅 | レイアウト特徴 |
|---------|--------|---------------|
| スマートフォン | 320px〜767px | 1カラム、全幅表示 |
| タブレット | 768px〜1023px | 中央寄せ、最大幅600px |
| PC | 1024px以上 | 中央寄せ、最大幅800px |

#### 検証方法

- Chrome DevToolsのデバイスエミュレーションで各画面幅を確認する
- 実機（スマートフォン）で操作確認を実施する

## 4. 性能要件

### NFR-003: 処理性能

| 項目 | 内容 |
|-----|------|
| 要件ID | NFR-003 |
| 項目名 | 処理性能 |
| 優先度 | SHALL（必須） |

#### 要件内容

| 仕様ID | 仕様内容 | 計測方法 |
|--------|---------|---------|
| NFR-003-01 | システムはタスク100件のリストを1秒以内に描画する | コンソールログで計測 |
| NFR-003-02 | システムはタスク追加を0.1秒以内に完了する | 体感で遅延がないこと |
| NFR-003-03 | システムはタスク削除を0.1秒以内に完了する | 体感で遅延がないこと |
| NFR-003-04 | システムはフィルタ切替を0.1秒以内に完了する | 体感で遅延がないこと |
| NFR-003-05 | システムはlocalStorage保存を0.1秒以内に完了する | 体感で遅延がないこと |

#### 制限事項

| 仕様ID | 仕様内容 |
|--------|---------|
| NFR-003-06 | タスク数の上限は1000件とする（localStorageの容量制限考慮） |
| NFR-003-07 | 1タスクあたりの文字数は200文字を上限とする |

#### 検証方法

- タスク100件を登録した状態でページ読込時間を計測する
- 各操作の体感遅延がないことを確認する

## 5. 保守性要件

### NFR-004: コード品質

| 項目 | 内容 |
|-----|------|
| 要件ID | NFR-004 |
| 項目名 | コード品質 |
| 優先度 | SHALL（必須） |

#### 要件内容

| 仕様ID | 仕様内容 |
|--------|---------|
| NFR-004-01 | JavaScriptコードは関数・クラス単位でコメントを付与する |
| NFR-004-02 | 変数名・関数名は役割を明確に示す命名とする |
| NFR-004-03 | 1関数あたりの行数は30行以内を目安とする |
| NFR-004-04 | UIロジックとビジネスロジックを分離する |
| NFR-004-05 | マジックナンバーは定数として定義する |
| NFR-004-06 | ES6+構文（const/let、アロー関数、テンプレートリテラル）を使用する |

#### 命名規則

| 対象 | 規則 | 例 |
|------|------|-----|
| 変数 | キャメルケース | `todoItems`, `currentFilter` |
| 関数 | キャメルケース、動詞始まり | `addTodo()`, `renderList()` |
| 定数 | 大文字スネークケース | `STORAGE_KEY`, `MAX_LENGTH` |
| CSSクラス | ケバブケース | `todo-item`, `filter-button` |
| ID属性 | ケバブケース | `todo-input`, `add-button` |

#### 検証方法

- コードレビューによる確認
- 命名規則の遵守確認

## 6. 使用性要件

### NFR-005: アクセシビリティ

| 項目 | 内容 |
|-----|------|
| 要件ID | NFR-005 |
| 項目名 | アクセシビリティ |
| 優先度 | SHOULD（推奨） |

#### 要件内容

| 仕様ID | 仕様内容 |
|--------|---------|
| NFR-005-01 | システムはセマンティックなHTML要素を使用する（header, main, button） |
| NFR-005-02 | フォーム要素にはlabel要素を関連付ける |
| NFR-005-03 | ボタンには適切なテキストまたはaria-labelを設定する |
| NFR-005-04 | キーボード操作で全機能が利用可能である |
| NFR-005-05 | フォーカス状態が視覚的に識別可能である |
| NFR-005-06 | 色のみに依存しない情報伝達を行う（完了状態は取り消し線も併用） |

#### 検証方法

- キーボードのみで全操作が可能かを確認する
- スクリーンリーダーでの読み上げ確認（オプション）

## 7. 移植性要件

### NFR-006: デプロイ容易性

| 項目 | 内容 |
|-----|------|
| 要件ID | NFR-006 |
| 項目名 | デプロイ容易性 |
| 優先度 | SHALL（必須） |

#### 要件内容

| 仕様ID | 仕様内容 |
|--------|---------|
| NFR-006-01 | システムはHTML、CSS、JavaScriptファイルのみで構成される |
| NFR-006-02 | システムはビルドツールなしで動作する |
| NFR-006-03 | システムはWebサーバーなしでローカルファイルとして動作する |
| NFR-006-04 | システムはGitHub Pagesで静的ホスティング可能である |
| NFR-006-05 | システムは外部ライブラリに依存しない |

#### ファイル構成

```
/
├── index.html      # メインHTML
├── styles.css      # スタイルシート
├── app.js          # アプリケーションロジック
└── README.md       # プロジェクト説明
```

#### 検証方法

- ローカル環境でHTMLファイルを直接ブラウザで開いて動作確認する
- GitHub Pagesにデプロイして動作確認する

## 8. セキュリティ要件

### NFR-007: クライアントサイドセキュリティ

| 項目 | 内容 |
|-----|------|
| 要件ID | NFR-007 |
| 項目名 | クライアントサイドセキュリティ |
| 優先度 | SHALL（必須） |

#### 要件内容

| 仕様ID | 仕様内容 |
|--------|---------|
| NFR-007-01 | システムはユーザー入力値をHTMLエスケープしてXSS攻撃を防止する |
| NFR-007-02 | システムはinnerHTMLの代わりにtextContentまたはDOM APIを使用する |
| NFR-007-03 | システムは機密情報を扱わない（パスワード、個人情報） |

#### 検証方法

- `<script>alert('XSS')</script>` をタスク名として入力し、スクリプトが実行されないことを確認する
- HTMLタグがエスケープされて表示されることを確認する

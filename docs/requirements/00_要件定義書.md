## 2. プロジェクト概要

### 2.1 背景・目的

#### 背景
- フロントエンドフレームワーク（React、Vue）を使用する前に、基礎となるJavaScriptの理解を深める必要がある
- 状態管理、DOM操作、ローカルストレージ操作を実践的に学習する場が必要である
- ポートフォリオとして技術力を示せる成果物を作成したい

#### 目的
本プロジェクトは、素のJavaScript（Vanilla JavaScript）を使用してToDoアプリケーションを開発し、以下を達成する：

1. **学習目的**: 状態管理、配列操作、localStorage、UIとロジックの分離を実践的に習得する
2. **成果物目的**: ポートフォリオに掲載できる品質のアプリケーションを完成させる

### 2.2 スコープ

#### スコープ内（本プロジェクトで実装する機能）

| 機能 | 概要 |
|------|------|
| ToDoアイテム追加 | テキスト入力によるアイテム追加 |
| ToDoアイテム削除 | 指定アイテムの削除 |
| 完了/未完了切り替え | アイテムの完了状態トグル |
| フィルタリング | すべて/未完了/完了の表示切替 |
| データ永続化 | localStorageへの保存・読込 |
| レスポンシブ対応 | PC/スマートフォン両対応 |

#### スコープ外（将来フェーズで検討する機能）

| 機能 | 理由 |
|------|------|
| インライン編集 | 学習範囲を超える複雑さ |
| 優先度・期限設定 | 学習範囲を超える複雑さ |
| カテゴリ分類 | 学習範囲を超える複雑さ |
| ユーザー認証 | サーバーサイド技術が必要 |
| データ同期（クラウド） | バックエンドが必要 |

### 2.3 前提条件

| 前提条件ID | 内容 |
|-----------|------|
| PRE-001 | ユーザーはモダンブラウザ（Chrome、Firefox、Edge最新版）を使用する |
| PRE-002 | ユーザーはJavaScriptを有効にしたブラウザを使用する |
| PRE-003 | ユーザーは単一のブラウザでアプリケーションを使用する（デバイス間同期は対象外） |

### 2.4 制約条件

| 制約条件ID | 内容 |
|-----------|------|
| CON-001 | フレームワーク（React、Vue、Angular）を使用しない |
| CON-002 | ビルドツール（webpack、Vite）を使用しない |
| CON-003 | バックエンドサーバーを使用しない |
| CON-004 | 外部APIを使用しない |
| CON-005 | localStorageの容量制限（5MB）の範囲内で動作する |

## テストケース

### TC-001: saveToStorage - 正常系

| 項目 | 内容 |
|------|------|
| テストID | TC-006-001 |
| 目的 | 正常なデータ保存 |
| 前提条件 | ブラウザがlocalStorageをサポート |

**手順:**

1. ブラウザでindex.htmlを開く
2. DevTools（F12）のConsoleタブを開く
3. 以下のコードを実行：

```javascript
import { saveToStorage } from './js/storage.js';

const testData = [
  { id: 'task-1', text: 'テストタスク', completed: false, createdAt: new Date().toISOString() }
];

saveToStorage(testData);
console.log('保存完了');
```

4. DevToolsのApplicationタブ → Storage → Local Storage → file://（またはドメイン）を開く
5. `vanilla-todo-items`キーが存在することを確認
6. 値がJSON配列形式であることを確認

**期待結果:**
- エラーなし
- localStorageにデータが保存される
- Consoleに「保存完了」と表示される

### TC-002: loadFromStorage - 正常系（データ存在）

| 項目 | 内容 |
|------|------|
| テストID | TC-006-002 |
| 目的 | 保存済みデータの読み込み |
| 前提条件 | TC-001で保存したデータが存在 |

**手順:**

1. DevTools Consoleで以下を実行：

```javascript
import { loadFromStorage } from './js/storage.js';

const loaded = loadFromStorage();
console.log('読み込んだデータ:', loaded);
console.log('配列か？', Array.isArray(loaded));
console.log('要素数:', loaded ? loaded.length : 'null');
```

**期待結果:**
- `loaded`が配列である
- 要素数が1である
- 最初の要素の`text`が「テストタスク」である

### TC-004: loadFromStorage - 異常系（JSON不正）

| 項目 | 内容 |
|------|------|
| テストID | TC-006-004 |
| 目的 | JSON解析失敗時の回復処理 |
| 前提条件 | - |

**手順:**

```javascript

```

```javascript
import { loadFromStorage } from './js/storage.js';

const result = loadFromStorage();
console.log('結果:', result);
```

3. DevTools Application → Local Storage で`vanilla-todo-items`が削除されたことを確認

**期待結果:**
- `result`が`null`である

  ```

  ```
- localStorageから`vanilla-todo-items`が削除される

### TC-006: saveToStorage - 異常系（容量超過）

| 項目 | 内容 |
|------|------|
| テストID | TC-006-006 |
| 目的 | QuotaExceededError発生時の動作確認 |
| 前提条件 | - |
| 備考 | 実際の容量超過を再現するのは困難なため、**オプショナル** |

**手順:**

1. 巨大な配列を作成して保存を試みる：

```javascript
import { saveToStorage } from './js/storage.js';

// 1000万文字の文字列を含むタスクを作成
const hugeTask = {
  id: 'huge-task',
  text: 'x'.repeat(10000000),
  completed: false,
  createdAt: new Date().toISOString()
};

saveToStorage([hugeTask]);
```

**期待結果:**
- Consoleに以下のエラーログが出力される：
  ```
  [vanilla-todo-fundamentals] localStorageへの保存に失敗: QuotaExceededError: ...
  ```
- アプリケーションがクラッシュしない

**注**: 容量制限はブラウザにより異なり、通常5MB程度です。

## 1. 発見・修正したバグ（Critical）

### 🚨 BUG-001: CSSクラス名の不一致（HTML vs CSS）

**カテゴリ**: UI/スタイル適用
**重大度**: ✋ **Critical**（全スタイルが適用されない致命的な問題）
**発見日時**: 2025-12-13

#### 問題の詳細

**HTML側（todoView.js）で生成されるクラス名:**
```javascript
// 修正前
<input class="todo-checkbox" ... />
<span class="todo-text completed" ... />
<button class="delete-button" ... />
```

**CSS側で定義されているクラス名:**
```css
.todo-item__checkbox { ... }
.todo-item__text { ... }
.todo-item__delete { ... }
.todo-item--completed .todo-item__text { ... }
```

**結果**: BEM記法のクラス名がHTMLとCSSで一致せず、以下のスタイルが一切適用されない:
- チェックボックスのサイズ・色
- タスクテキストのスタイル
- 削除ボタンの背景色・ホバーエフェクト
- 完了タスクの取り消し線

**影響範囲**:
- すべてのタスクアイテムが無スタイル状態
- ユーザビリティが著しく低下
- 完了/未完了の視覚的区別が不可能

#### 根本原因

1. CSS設計時にBEM記法（`Block__Element--Modifier`）を採用
2. JavaScript実装時に旧来のクラス名を使用
3. 設計書とコードの同期が取れていなかった

#### 修正内容

**修正ファイル1: `src/js/todoView.js`**

```diff
function createTodoItemHTML(todo) {
  const checkedAttr = todo.completed ? 'checked' : '';
- const completedClass = todo.completed ? 'completed' : '';
+ const completedClass = todo.completed ? 'todo-item--completed' : '';

  return `
-   <li class="todo-item" data-id="${todo.id}" role="listitem">
+   <li class="todo-item ${completedClass}" data-id="${todo.id}" role="listitem">
      <input
        type="checkbox"
-       class="todo-checkbox"
+       class="todo-item__checkbox"
        data-id="${todo.id}"
        ${checkedAttr}
        aria-label="タスクを完了にする"
      />
-     <span class="todo-text ${completedClass}">${escapeHTML(todo.text)}</span>
+     <span class="todo-item__text">${escapeHTML(todo.text)}</span>
      <button
-       class="delete-button"
+       class="todo-item__delete"
        data-id="${todo.id}"
        aria-label="タスクを削除"
      >
        削除
      </button>
    </li>
  `;
}
```

**修正ファイル2: `src/js/app.js`**

```diff
  todoList.addEventListener('click', (event) => {
    const target = event.target;

    // 削除ボタンのクリック
-   if (target.classList.contains('delete-button')) {
+   if (target.classList.contains('todo-item__delete')) {
      const id = target.dataset.id;
      handleDeleteTodo(id);
    }

    // チェックボックスのクリック
-   if (target.classList.contains('todo-checkbox')) {
+   if (target.classList.contains('todo-item__checkbox')) {
      const id = target.dataset.id;
      handleToggleTodo(id);
    }
  });
```

#### 修正後の動作確認

✅ チェックボックスが正しいサイズ（44x44px）で表示される
✅ 削除ボタンが赤色の背景色で表示される
✅ ホバー時にタスクの背景色が薄青色（`#F0F7FF`）に変化する
✅ 完了タスクに取り消し線が表示される
✅ 完了タスクのテキスト色が薄くなる（`opacity: 0.7`）

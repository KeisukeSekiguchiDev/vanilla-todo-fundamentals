## テスト実施手順

### 1. 準備

#### 必要なもの
- モダンブラウザ（Chrome/Firefox/Edge 最新版）
- 開発者ツール（F12で開く）

#### ブラウザ設定
- JavaScriptを有効化
- localStorageを有効化
- プライベートモードは使用しない（localStorageが無効になるため）

---

### 2. 自動テスト実行

#### 手順

1. **テストページを開く**

   以下のいずれかの方法でファイルを開く：

   - 方法A: ファイルエクスプローラーからダブルクリック
     ```
     tests/functional-test.html
     ```

   - 方法B: ブラウザのアドレスバーに直接入力
     ```
     file:///C:/Users/Sekiguchi/source/repos/Dev/vanilla-todo-fundamentals/tests/functional-test.html
     ```

   - 方法C: VSCodeでLive Serverを使用（推奨）
     ```
     右クリック → "Open with Live Server"
     ```

2. **開発者ツールを開く**

   - F12キーを押下
   - または右クリック → 「検証」
   - コンソールタブを確認

3. **自動テスト実行**

   - 「自動テスト実行」ボタンをクリック
   - テスト実行が開始される（約1秒）

4. **結果確認**

   - 画面上部に「テストサマリー」が表示される
   - 各テストケースの成功/失敗が表示される
   - コンソールにも詳細ログが出力される

#### 期待される結果

```
📊 テストサマリー
総テスト数: 13件
成功: 13件
失敗: 0件
成功率: 100%
```

---

### 3. 手動確認項目

自動テストでは検証できない項目を手動で確認します。

#### 3.1 Enterキーで追加（FR-001）

**手順:**
1. 入力欄に「テストタスク」と入力
2. Enterキーを押下

**期待結果:**
- ✅ タスクがリストに追加される
- ✅ 入力欄がクリアされる
- ✅ フォーカスが入力欄に残る

---

#### 3.2 ページリロード後もデータ維持（FR-005）

**手順:**
1. 複数のタスクを追加
2. 一部のタスクを完了状態にする
3. ページをリロード（F5キー）

**期待結果:**
- ✅ リロード前のタスクが全て表示される
- ✅ 完了状態も維持される
- ✅ フィルタ状態もリセットされる（「すべて」が選択）

---

#### 3.3 レスポンシブデザイン

**手順:**
1. ブラウザウィンドウを縮小（幅375px程度）
2. レイアウトを確認

**期待結果:**
- ✅ ボタンが小さくなる
- ✅ テキストが折り返される
- ✅ レイアウトが崩れない

---

#### 3.4 アクセシビリティ

**手順:**
1. Tabキーを数回押下してフォーカスを移動
2. Enterキーで各種操作を実行

**期待結果:**
- ✅ Tabキーでフォーカス順序が論理的
- ✅ フォーカスが視覚的に分かる
- ✅ Enterキーで追加・フィルタ変更が可能
- ✅ Spaceキーでチェックボックスの切替が可能

---

### 4. データリセット

テストデータをクリアする場合：

1. 「データリセット」ボタンをクリック
2. 確認ダイアログで「OK」をクリック
3. タスクリストが空になる

## トラブルシューティング

### テストが失敗する場合

#### 問題: localStorageエラー

**症状:**
```
[vanilla-todo-fundamentals] localStorageへの保存に失敗
```

**原因:**
- プライベートモードで実行している
- ブラウザのlocalStorageが無効化されている

**対処法:**
1. 通常モードで開く
2. ブラウザ設定でlocalStorageを有効化

---

#### 問題: モジュールが読み込めない

**症状:**
```
Failed to load module script: ... CORS policy
```

**原因:**
- file://プロトコルでモジュールが読み込めない

**対処法:**
- Live Server等のローカルサーバーを使用
- または以下のいずれかのブラウザフラグを有効化：
  - Chrome: `--allow-file-access-from-files`
  - Firefox: `about:config` → `security.fileuri.strict_origin_policy` → false

---

#### 問題: アプリが初期化されない

**症状:**
- タスクリストが表示されない
- ボタンが反応しない

**原因:**
- JavaScriptエラーが発生している

**対処法:**
1. F12で開発者ツールを開く
2. コンソールタブでエラーを確認
3. エラーメッセージに従って対処

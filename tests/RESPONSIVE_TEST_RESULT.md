## 実装内容のまとめ

### モバイルファースト設計の適用

#### Before（デスクトップファースト）
```css
/* デフォルトがデスクトップ向け */
.input-section {
  display: flex;
  gap: var(--spacing-md);
}

/* モバイル向けに上書き */
@media (max-width: 767px) {
  .input-section {
    flex-direction: column;
  }
}
```

#### After（モバイルファースト）
```css
/* デフォルトがモバイル向け */
.input-section {
  display: flex;
  flex-direction: column;
  gap: var(--spacing-md);
}

/* タブレット以上で拡張 */
@media (min-width: 768px) {
  .input-section {
    flex-direction: row;
  }
}
```

### 主な変更箇所

| 要素 | モバイルベース（デフォルト） | タブレット以上（768px+） |
|------|---------------------------|------------------------|
| header h1 | 2rem (32px) | 2.5rem (40px) |
| main | margin: 16px, padding: 16px | max-width: 600px, margin: 24px auto |
| .input-section | flex-direction: column | flex-direction: row |
| #add-button | width: 100% | width: auto |
| .filter-section | flex-wrap: wrap | flex-wrap: nowrap |
| .filter-button | flex: 1 | flex: initial |
| .todo-item | flex-wrap: wrap, gap: 8px | flex-wrap: nowrap, gap: 16px |
| .todo-item__delete | margin-left: auto | margin-left: 0 |
